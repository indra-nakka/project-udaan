# 🎨 Aesthetic Canvas

Keep color hex codes (the sunset Ghibli color palette) and asset dimensions right inside the notes so your minimalist UI design guidelines remain exact throughout development.

## UI Guidelines
- **Theme:** Minimalist, non-intrusive. Let the Ghibli environment breathe.
- **HUD Elements:**
  - Health Bar (Top Left)
  - Scrap Counter (Top Right, using a gear/bolt icon)
- **Colors:**
  - Scrap/Gold: `#FFD700`
  - Health/Friendly: `#4CAF50`
  - Background panels: Semi-transparent black (`#000000` at 40% opacity)
- **Typography:** TextMeshPro, bold, rounded sans-serif.

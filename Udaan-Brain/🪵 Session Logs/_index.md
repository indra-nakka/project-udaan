# 🪵 Session Logs — Index (MOC)

**Role:** Map of Content for session logs. Per-change history is the single source of truth in [[changelog]] — this page is for *navigation*, not duplication.

## How to use
- Each session creates one file `YYYY-MM-DD-HHMM.md` from [[session-template]].
- To catch up: open this folder, sort by name (descending), read the **last ~5** logs' Goal + Summary lines.
- For the per-change ledger across all sessions, read [[changelog]].

## Logs by phase
- **Phase 1–2 — Core offline & scrap economy:** `2026-06-16-0130`, `2026-06-16_Phase3`, `2026-06-19-0050`, `2026-06-19-1045`
- **Phase 3–4 — Classes, spawner, network sandbox (DRONE/DOC series):** `2026-06-26-0006` → `2026-06-26-0400` (DRONE-01…10, DOC-01…03)
- **Brain & planning pass:** see `changelog` sessions 022–024 (strategy docs, milestone roadmap, audit).

> When the list grows unwieldy, keep only the phase headings here and let date-sorting + [[changelog]] do the rest.
